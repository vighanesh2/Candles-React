Candles-React
A premium candle business showcase website with stunning visuals and seamless user experience.
Overview
This repository contains a modern, elegantly designed frontend for a luxury candle business. The website was built with a focus on aesthetic excellence, smooth animations, and responsive design to beautifully showcase artisanal candle products.
Key Features

Stunning Visual Design: Elegant typography, curated color palette, and sophisticated layout
Product Showcase: Beautiful product photography highlighting each candle's unique qualities
Seamless Animations: Subtle micro-interactions and transitions that enhance user experience
Fully Responsive: Perfect viewing experience across all devices from mobile to desktop
Performance Optimized: Fast loading times and smooth scrolling

Tech Stack

React.js
CSS/SCSS for styling
Framer Motion for animations
Responsive design principles


Design Elements

Custom typography pairing
Warm, inviting color scheme
High-quality product photography
Minimalist UI elements
Elegant hover states and transitions

Installation and Setup
